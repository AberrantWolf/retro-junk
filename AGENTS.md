# Repository guidance

Specialized project knowledge is maintained as skills in `.claude/skills/`.
Before working in one of these areas, read the corresponding `SKILL.md` and
only the directly relevant reference files it links to:

- `game-scraping`: DAT sources, ScreenScraper, ROM identification, hashes,
  metadata, and media acquisition.
- `gaming-frontends`: frontend metadata and media formats, including ES-DE.
- `retro-archive`: disc/archive formats, console-specific dump structures,
  Redump, and preservation workflows.

The same directories are installed as personal Codex skills when available;
this file keeps the knowledge discoverable for every agent working in this
repository.
